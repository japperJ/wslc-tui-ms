# Report A Problem

Include enough information for another person to reproduce the failure.

## Collect The Basics

- Application version from `wslc-tui.exe --version`.
- Release asset name or source commit.
- Windows version and architecture.
- Terminal application.
- Whether the MSI, bootstrapper, portable ZIP, or source run was used.
- Whether `wslc --help` succeeds.

## Describe The Failure

Include:

1. The exact steps taken.
2. The expected result.
3. The actual result.
4. The smallest command or resource that reproduces it.
5. Any visible error text.

Redact passwords, tokens, registry secrets, private image names, and customer data. Do not attach unverified binaries or full terminal recordings containing secrets.
